# Blackhole Client — kurulum dosyaları

Bu depo sadece **Blackhole Client** kurulum dosyalarını ve uygulamanın kendiliğinden güncellemesi için gereken `latest.yml` dosyasını barındırır. Kaynak kod burada değildir.

- İndirmek için: [Releases](https://github.com/Anomalyfr/blackhole-client-releases/releases/latest) → `Blackhole-Client-Setup-<sürüm>.exe`
- Kurulu uygulama yeni sürümü buradan kendisi indirir; indirilen dosyanın SHA-512 özeti ve Authenticode imzası (Blackhole Client sertifikası) denetlenir.
- Windows "Bilinmeyen yayımcı" uyarısı verirse: **Ek bilgi → Yine de çalıştır**.
